# Новое лобби: план

> [!abstract] Цель
> Лобби в каркасе игрового лаунчера: одно главное действие «Один на один», столы для компаний 3–6 красивыми карточками в карусели, последняя партия, статистика, чат сервера и рейка друзей. Убираем путаницу «Играть / Свой стол / Собрать стол / По ссылке».

Ветка: `feature/lobby-launcher` от `main`.

> [!note] Оформление позже
> Этот план про структуру и логику. Картинки столов, карточек и насыщенные темы с ярким акцентом — отдельная задача после него.

## 1. Каркас экрана

```
┌──────┬──────────────────────────────────────────┬───────────────┬──────┐
│ меню │ приветствие, баланс                      │               │ друзья│
│ блок │ ┌──────────────────────────────────────┐ │  Статистика   │ рейка │
│      │ │ Один на один · настройки · Играть    │ │               │       │
│      │ └──────────────────────────────────────┘ │               │       │
│      │ Компании на 3–6        Все столы →       │  Чат сервера  │       │
│      │ [стол][стол][стол][+ создать] →          │               │       │
│      │ Последняя партия       История →         │               │       │
└──────┴──────────────────────────────────────────┴───────────────┴──────┘
```

| Ширина | Раскладка |
|---|---|
| ≥ 1280 | всё как на схеме |
| 768–1279 | рейка друзей скрыта (друзья в панели), статистика и чат под последней партией |
| < 768 | меню внизу вкладками, одна колонка: герой → карусель → последняя партия → статистика → чат |

## 2. Что настоящее, что заглушка

| Блок | Данные |
|---|---|
| Один на один | **настоящее** |
| Карусель и «Все столы» | **настоящее**, `GET /tables` |
| Создать стол | **настоящее** |
| Последняя партия, история в профиле | **настоящее**, новый `GET /users/me/games` |
| Статистика: игры, победы, % | **настоящее**, профиль |
| Статистика: серия побед | **настоящее**, считается из истории |
| Реванш | заглушка «скоро» |
| Чат сервера | заглушка до лобби-сокета |
| Друзья | заглушка (бэкенда друзей нет) |

## 3. Этапы

### Этап 1. Бэкенд

1. **Быстрая игра 1 на 1** `POST /api/v1/tables/quick`:
   - всегда 2 игрока, `maxPlayers` в теле больше не нужен;
   - `mode` может быть `"any"`, `deck` может быть `0` (любая);
   - подходит ожидающий стол на 2 с той же ставкой, где режим и колода совпадают или запрошены как «любые»;
   - если не нашли — создаём стол: «любой» режим → подкидной, «любая» колода → 36.
2. **Столы на 2 скрыты.** `RoomSettings.Matchmaking`: такие столы не попадают в `GET /tables`.
3. **`POST /tables` только для компаний:** `maxPlayers` от 3 до 6.
4. **История партий** `GET /api/v1/users/me/games?limit=20`: `{id, finishedAt, mode, deck, players, stake, place, payout}`, только завершённые партии. Формат совпадает с `GameHistoryEntry` на фронте.
5. Тесты: подбор с «любым», скрытие столов на 2, валидация 3–6, история (интеграционный тест на Postgres).

### Этап 2. Каркас лобби

1. Новая сетка `LobbyView`: меню | центр | правая колонка | рейка друзей.
2. `NavRail` в виде отдельного скруглённого блока, как в референсе.
3. Новый `FriendsRail.vue`: аватары, точки онлайн, метка «в игре», кнопка «добавить». Клик открывает существующую панель «Друзья и чат».
4. `SocialPanel` из правой колонки уходит: чат переезжает в центр-справа, друзья — в рейку.

### Этап 3. Герой «Один на один»

1. Новый `QuickPlay.vue` вместо `PlayPanel.vue`: ставка, режим и колода как компактные выпадающие поля, у режима и колоды есть «Любой». Выбор запоминается в `localStorage`.
2. Кнопка «Играть» и строка «выигрыш +475 / проигрыш −500».
3. **Поиск соперника:** за столом на 2, пока соперника нет, вместо «Ожидание» экран «Ищем соперника» с таймером и кнопкой «Отмена» (уходит в лобби и освобождает место).

### Этап 4. Компании 3–6

1. `TablesCarousel.vue`: лента карточек-мини-столов, стрелки, последняя карточка — «Создать стол».
2. Карточка стола: сукно с местами, ставка фишкой на столе, режим, колода, места, «Сесть» или «Мало фишек».
3. «Все столы» — панель поверх лобби: фильтры по игрокам (3–6), режиму и ставке («По карману», 100, 250, 500, 1K+), сортировка («почти полные», «новые», «по ставке»), сетка карточек.
4. `CreateTableDialog.vue`: ставка, режим, колода, игроки 3–6, «Создать и сесть».

### Этап 5. Последняя партия и статистика

1. `LastGame.vue`: место, режим, колода, число игроков, когда, итог `+475 / −500`, «Реванш» (скоро), «История →» открывает профиль.
2. `StatsCard.vue`: кольцо % побед, игры, победы, серия.
3. История в профиле берётся с сервера вместо `MOCK_HISTORY`.

### Этап 6. Чистка и проверка

1. Удалить `PlayPanel.vue`, `TablesBoard.vue`, лишние моки.
2. Проверить в браузере на трёх ширинах, светлая и тёмная темы.
3. Обновить `features.md`.

Каждый этап — отдельный коммит, после каждого всё собирается и тесты зелёные.
