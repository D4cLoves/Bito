# Новое лобби: как сделано

> [!abstract] Итог
> Лобби в каркасе игрового лаунчера: одно главное действие «Один на один», компании на 3–6 игроков красивыми карточками в карусели, экран «Все столы» с фильтрами, одно окно «Новый стол», карточка игрока с последними партиями и рейка друзей. Лобби помещается в экран без прокрутки. Путаница «Играть / Свой стол / Собрать стол / По ссылке» ушла.

> [!note] Оформление позже
> Структура и логика готовы. Картинки столов, карточек и насыщенные темы с ярким акцентом — отдельная задача. Тёмная тема «Зал» с зелёным сукном уже выглядит близко к нужной насыщенности.

```
│ меню │ Добрый день, Ника                          2 975 │ друзья│
│ блок │ ┌──── Один на один ─────┐ ┌─ (Н) Ника · 67% ───┐ │ рейка │

│      │ └───────────────────────┘ │ Последняя · Ещё    │ │       │
│      │                           └────────────────────┘ │       │
│      │ Компании на 3–6  фильтры              Все столы → │       │
│      │ [стол][стол][стол][стол][+ свой стол]             │       │
└──────┴──────────────────────────────────────────────────┴───────┘
```

| Ширина | Раскладка |
|---|---|
| ≥ 1280 | как на схеме; у героя справа веер карт и стопка фишек (если герой шире 780 px) |
| 1101–1279 | рейка друзей скрыта, в шапке кнопки «Друзья» и профиль |
| ≤ 1100 | карточка игрока встаёт под героя |
| ≤ 1180 | фильтры в шапке компаний скрыты (есть в «Все столы») |
| < 768 | меню — нижние вкладки, всё в одну колонку, шапка компаний переносится, стрелки карусели скрыты |

- **Правой колонки нет.** Карточка игрока стоит в одном ряду с героем, той же высоты и на том же сукне: пара «играть» и «кто я».
- **Столы обычного размера**, без растягивания под высоту экрана: пять в ряд, дальше листаются. На невысоком экране (≤ 920 px) стол чуть ниже.

## 3. Как работает «Играть» (1 на 1)

1. Игрок выбирает ставку, режим и колоду. У режима и колоды есть «Любой». Выбор запоминается (`bito_quick_play` в `localStorage`).
2. `POST /api/v1/tables/quick {mode, deck, stake}` — `mode` может быть `"any"`, `deck` может быть `0`.
3. `Hub.MatchOrCreate` **под одной блокировкой** ищет ожидающий стол на двоих с той же ставкой и подходящими режимом и колодой. Не нашёл — создаёт (`any` → подкидной, колода → 36).
4. Место **бронируется на 15 секунд**, пока игрок не подключился по сокету. Поэтому одновременное «Играть» двух игроков сводит их за один стол, а третий в дуэль не попадёт.
5. Столы на двоих помечены `matchmaking` и **не попадают** в общий список. Стол узнаёт о себе через `GET /api/v1/tables/{id}`.
6. Экран «Ищем соперника»: радар, настройки стола, таймер, «Отменить поиск». Отмена уводит в лобби, место освобождается, пустой стол закрывается.

> [!warning] Ограничение «Любого»
> «Любой» помогает **найти** чужой стол. Если подходящего нет, игрок ждёт за конкретным столом (подкидной, 36), и соперник с «переводным» к нему не сядет. Для честной очереди с «любым» нужен отдельный матчмейкер — на потом.

## 4. Компании на 3–6

- `POST /api/v1/tables` теперь только для 3–6 игроков.
- **Карусель** — до 12 столов, пять в ряд: по карману вперёд, почти собранные выше. В шапке фильтры: «По карману», «Подкидной» / «Переводной», ставка 100 / 250 / 500+, «Сбросить». В конце всегда карточка «Свой стол».
- **Пусто** — вместо живых столов приглушённые готовые: 3 · 100, 4 · 250 переводной, 6 · 500, 5 · 1000 переводной на 52. Кнопка «Создать» создаёт стол в один клик, недоступные по фишкам — «Мало фишек».
- **Карточка стола** (`TableTop` + `TableCard`) — стол сверху: деревянный бортик, сукно цвета выбранного сукна, фишка ставки в центре, кресла по кругу. Свободное кресло — «+», занятое — кремовое с силуэтом (имён игроков API не отдаёт), на своём столе первое кресло — ваш аватар с золотым кольцом. Под столом: режим · колода, «N из M · когда», «выигрыш до +X», кнопка «Сесть» (или «Ждём игроков…» на своём, «Мало фишек»). Метки «ваш» и «ещё 1 место» — в углу.
- **«Все столы»** (`?panel=tables`) — фильтры по игрокам, режиму и ставке («По карману», «Все», 100, 250, 500, «1K и выше»), сортировка «Почти полные / Новые / по ставке».
- **«Новый стол»** — жетоны ставок, режим, колода, игроки (не помещающиеся в колоду блокируются), расчёт выигрыша. Выбор запоминается (`bito_create_table`). Esc закрывает только окно, даже поверх панели.

## 5. Карточка игрока

- `GET /api/v1/users/me/games?limit=20` → `{id, finishedAt, mode, deck, players, stake, place, payout, outcome}`.
- **Шапка:** аватар с золотым кольцом, имя курсивом, звание по числу партий (`rankTitle`: Новичок → Игрок → Завсегдатай → Мастер стола). Клик по аватару открывает профиль.
- Без кольца и плиток: цифры набраны курсивом прямо на сукне.
- **Последние партии — мини-картами**, 6 в ряд. Победа — открытая карта (корона за первое место, сумма зелёным), поражение — карта рубашкой (красная, сумма), ничья — бледная карта. Пустые места — пунктирные рамки. Подсказка с деталями по наведению.
- **Строка итогов:** партий, побед подряд, лучший выигрыш. Процент побед крупно справа от имени.
- **Последняя** внизу одной полосой: исход, сумма, детали и **«Ещё партия»** — для дуэли запускает поиск с теми же настройками, для компании открывает «Новый стол» с ними же. Если фишек стало меньше, ставка опускается до доступной.
- **История в профиле** с сервера. Ничья показывается как «ничья, 0», а не «−0».

Общего чата в лобби нет: решили, что хватает чата за столом. Переключатель «Общий чат в лобби» в настройках убран.
